# ✦ Dev Nova AI

> An AI-powered developer assistant for code analysis, GitHub exploration, and Git version-control intelligence.

## 📌 Project Overview

**Dev Nova AI** is a web-based developer assistant developed using Python and Flask.

The application brings several useful developer tools together in one platform. Users can analyze Python code, explore public GitHub profiles, and view real-time Git information from the project's repository.

The project also demonstrates practical use of **APIs, Machine Learning, Flask, JavaScript, Git, and GitHub**.

---

## ✨ Main Features

### 🤖 AI Code Analyzer

The Code Analyzer allows users to enter Python code and receive analysis from the application.

Features include:

- Python code input
- Code analysis
- Error detection
- Developer feedback
- Machine-learning based functionality

---

### 🐙 GitHub Intelligence

The GitHub Intelligence feature uses the GitHub API to retrieve public developer information.

Users can enter a GitHub username and explore:

- 👤 Developer profile
- 📦 Public repositories
- ⭐ Repository stars
- 🍴 Repository forks
- 💻 Programming languages
- 🔗 Repository information
